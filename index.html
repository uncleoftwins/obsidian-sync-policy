Obsidian GSync Integration

이 웹 애플리케이션은 개인 사용자가 Obsidian 노트와 첨부파일을 개인 Google Drive 저장소와 동기화하기 위한 개인용 도구입니다.

개인정보처리방침 (Privacy Policy)

  1. 데이터 수집 및 전송: 본 애플리케이션은 사용자의 어떠한 개인정보, 노트 내용, 계정 인증 정보를 외부 제3자 서버로 수집·전송하지 않습니다.
  2. Google API 접근: Google Drive API는 오직 사용자가 지정한 로컬 디렉터리와 Google Drive 폴더 간의 파일 읽기/쓰기/동기화 목적으로만 직접 통신에 사용됩니다.
  3. 토큰 저장: 발급된 인증 토큰은 사용자의 로컬 기기(Obsidian 설정 경로)에만 보관됩니다.
  4. 문의: 개인 사용 용도이므로 별도의 외부 사용자 지원은 제공하지 않습니다.
